# Security Policy

## Supported Versions

Security updates are provided for the latest release series only.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Use one of the following channels:

1. GitHub Security Advisories (preferred): open a private report in the repository Security tab.
2. If advisories are unavailable, open an issue titled `Security: private report requested` with no exploit details,
   and a maintainer will provide a private channel.

When reporting, include:

- Affected component and version/commit
- Reproduction steps or proof-of-concept
- Impact assessment
- Any suggested remediation

We aim to acknowledge reports within 5 business days.
