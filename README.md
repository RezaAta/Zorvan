# ComputationalGraphs

ComputationalGraphs is a repository for implementing computational graph architectures and experiments across different modeling paradigms (MLP, ANFIS, Fuzzy Systems, Evolutionary Algorithms).

See `COPILOT_README.md` and `AGENT_POLICY.md` for agent usage guidance and contribution rules. Use `CONTRIBUTING.md` for guidelines, and run `scripts/run_checks.ps1` to validate code locally.

Quick run:

```powershell
python run_gui.py
python CompareThreeApproaches.py
```
