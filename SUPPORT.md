# Support

## Getting Help

- Usage questions: open a GitHub Discussion (or issue if Discussions are disabled).
- Bug reports: use the Bug Report issue template.
- Feature requests: use the Feature Request issue template.

## What to Include

Please include:

- Python version and OS
- Reproduction steps
- Expected vs actual behavior
- Minimal script or graph that reproduces the problem

## Response Expectations

This project is maintained in available time. Response times can vary, but
maintainers will triage new reports as capacity permits.
